# Crédits

**Français** · [English](NOTICE_EN.md)

Pocket Rally s’inspire de la course vue de dessus et du défilement par tuiles de **[Tiny CarZ](https://www.ticalc.org/archives/files/fileinfo/391/39185.html)**, créé par **Léo Ducas / Kuda-Soft** pour TI-83 Plus.

Le code Z80 Sharp, le tilemapper, les graphismes, les circuits et les outils de Pocket Rally sont des créations originales de P.RAIMBAULT, distribuées sous [licence MIT](../../LICENSE.txt). Aucun code, binaire, circuit, graphisme ou outil provenant de l’archive Tiny CarZ n’est redistribué avec ce projet. Tiny CarZ conserve les droits et conditions de son auteur.

Les définitions matérielles et IOCS Sharp sont référencées dans [l’include commun](../../include/sharp-pc-g8xx.inc). Les routines de composition de sprites proviennent du code Pocket Jumper de cette collection, également sous MIT.
